Inventory & Par Level Admin

Edit item names, units, and par levels for every property, all in one place.

How this works: This page is not connected to a database — it's a tool for editing your inventory list and generating updated code.

Manage Items (below) lets you rename items or categories, change units, add or remove items, and set each item's default par level and Spanish translation. Par Levels by Property (further down) lets you override an item's par level for one specific property only.

When you're done, scroll to the bottom and click Generate updated code. It produces the full updated contents of three files: assets/items.js, assets/i18n.js, and assets/par-overrides.js. Copy each one and paste it over the matching file on GitHub, the same way you've been updating other files. Nothing changes on the live site until you do that.

Heads up: renaming an item or a category clears any progress cleaners have already saved for it on their own devices, since their saved checklist entries are matched by name. Deleting an item removes it (and any saved progress for it) from every cleaner's checklist.
