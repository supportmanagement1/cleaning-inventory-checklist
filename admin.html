Par Level Admin

Edit minimum (par) levels for every property, all in one place.

How this works: This page is not connected to a database — it's a tool for editing numbers and generating updated code. Adjust any par level below (fields you change are highlighted), then scroll down and click Generate updated code. Copy the result and paste it over assets/par-overrides.js on GitHub, the same way you've been updating other files. Nothing changes on the live site until you do that.
